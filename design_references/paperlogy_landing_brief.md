# Paperlogy 랜딩 스타일 브리핑

- 관찰일: 2026-09-16
- 원본: https://freesentation.blog/paperlogyfont
- 재관찰일: 2026-09-16. 데스크톱과 390px 모바일 뷰에서 히어로, ABOUT 전환 중간 프레임, FEATURE 1~7, INFO, 하단 다운로드를 직접 스크롤했다. 브라우저에서 표시 위치·스타일도 확인했다.

## 한 문장 정의

**타이포그래피를 이미지처럼 쓰는 에디토리얼 쇼케이스 랜딩.** 큰 글자·검정/파랑 색면·실물 비교를 이어 붙이고, 스크롤을 패널 교체와 번호별 증거 제시의 리듬으로 만든다. 글자 자체가 움직이는 장면보다 **패널의 중첩, 연속 회전하는 번호 도형, 옆에서 날아오는 증거 카드**가 시그니처 모션이다.

## 관찰된 디자인 문법

| 요소 | 화면에서 확인한 모습 | 통용 명칭 / 구현 어휘 |
| --- | --- | --- |
| 히어로 | 화면 하단을 가로지르며 일부가 잘리는 초대형 파란 `PAPERLOGY.` 워드마크 | oversized typography, viewport-cropped type, display wordmark |
| 첫 화면 메뉴 | 왼쪽의 굵은 대문자 `ABOUT / FEATURE / LICENSE / DOWNLOAD`가 콘텐츠 자체처럼 놓임 | typographic navigation, editorial navigation |
| 색 | 흰색·검정·선명한 로열/코발트 블루의 강한 면 대비 | high-contrast color blocking, section theming |
| 섹션 | 검정·파랑·검정의 큰 둥근 패널이 한 장씩 위로 올라와 이전 패널을 덮음. 데스크톱에서는 흰 바깥 여백이 남음 | sticky card stack / overlapping panels |
| 구성 | 왼쪽 큰 주장, 오른쪽 샘플·근거의 2열 배치. 숫자·단어가 그래픽을 대신함 | editorial grid, split layout, typographic data visualization |
| 비교 | 굵기 9종, 자간, 커닝, 숫자 폭, 파일 크기를 같은 시야 안에서 나란히 보여줌 | specimen sheet, side-by-side comparison, proof-led storytelling |
| 넘버링 | 왼쪽에 파란 둥근 사각형이 연속 회전하고 흰 숫자 1~7이 차례로 바뀜. 오른쪽 근거가 지나가는 동안 마커 위치는 유지 | sticky numbered rail + rotating square |
| 내비게이션 | 스크롤 중에도 좌상단 `HOME`, 우상단 세로 조판 `GO TO DOWNLOAD`가 보임 | persistent / sticky navigation, persistent CTA |
| 하단 | 검정 패널 안에서 큰 다운로드 링크와 대형 파란 워드마크로 마감 | typographic CTA, bookend composition |

파랑은 화면 관찰 기준의 **근사치**이며 코드에서 원본의 정확한 색상 토큰을 측정한 값은 아니다. 재현 작업에서는 브랜드에 맞는 자체 토큰을 정해야 한다.

## 확인한 동작의 순서와 상태

| 효과 | 트리거와 실제 관찰 | 브라우저에서 확인한 구조 |
| --- | --- | --- |
| ABOUT 패널 스택 | 첫 검정 패널이 화면에 머물고, 다음 파랑 패널의 둥근 윗모서리가 아래에서 올라와 검정을 덮는다. 이어 다음 검정 패널이 같은 방식으로 파랑을 덮는다. 패널이 완전히 올라온 뒤 다음 장으로 넘어간다. | ABOUT의 3개 패널 래퍼가 각각 약 한 뷰포트 높이이며 `position: sticky; top: 0`. 내부 색면은 약 60px 라운드. 데스크톱 양옆에 약 24px 흰 여백. |
| FEATURE 번호 레일 | 흰 배경으로 넘어가면 파란 숫자 도형이 왼쪽의 거의 같은 위치에 붙는다. 오른쪽의 1~7번 설명이 스크롤에 따라 교체될 때 숫자도 바뀌며, 파란 도형은 가만히 있는 동안에도 계속 회전한다. 숫자는 읽을 수 있게 정방향으로 남는다. | 숫자 컴포넌트의 부모는 `position: sticky`. 파란 사각형에 계속 달라지는 `rotate(...)` 인라인 스타일이 관찰됐다. 이는 스크롤 위치와 별개로 진행되는 회전으로 보인다. |
| FEATURE 근거 카드 진입 | 각 번호의 오른쪽 제목·설명·비교/이미지 묶음이 차례로 오른쪽에서 들어와 자리를 잡는다. 이전 항목은 위로 지나가고 다음 항목이 나타난다. | 아직 화면 밖인 카드에 `opacity: 0; transform: translateX(192px) scale(0.9)`, 들어온 카드에 거의 `opacity: 1; transform: none`이 관찰됐다. 정확한 이징·트리거 설정은 확인하지 않았다. |
| 고정 길잡이와 앵커 | 좌상단 HOME, 우상단 세로 조판 GO TO DOWNLOAD가 여러 장면에서 같은 화면 위치에 남는다. 우상단 버튼을 누르면 하단 검정 다운로드 패널로 이동한다. | 버튼의 고정 위치는 화면에서 관찰했다. 내부 구현의 `fixed`/`sticky` 여부는 확인하지 않았다. |
| 모바일 재배치 | 390px 폭에서 ABOUT 패널은 거의 전체 폭을 채운다. FEATURE 번호 도형은 작아져 상단 왼쪽에 남고, 설명·이미지는 그 아래 한 열로 흐른다. | 모바일에서도 번호 마커가 내용이 바뀌는 동안 화면에 남는 것을 확인했다. 일부 원본 이미지의 가로 잘림은 원본 동작이며 새 제작물의 필수 규칙은 아니다. |

관찰한 FEATURE 내용은 1~7까지다. 사용자가 특히 주목한 1~5에도 같은 반복 패턴이 적용된다. 정지 화면만 보면 오른쪽 카드의 진입 전 위치와 패널 중첩을 놓치기 쉬우므로 전환 중간 프레임을 확인해야 한다.

## 효과 이름을 구분해서 쓰기

1. **오버사이즈/크롭 타이포그래피**: 글자를 이미지처럼 크게 만들고 뷰포트에서 의도적으로 일부를 자른다. `clamp()` 크기와 `overflow: hidden`으로 구현 가능하다.
2. **컬러 블로킹**: 흰색 → 검정 → 파랑처럼 섹션 전체의 배경색을 전환해 장면을 구분한다. 그라데이션이나 그림자보다 면의 대비가 핵심이다.
3. **스티키 카드 스택**: `sticky`인 화면 높이 패널 세 장이 검정 → 파랑 → 검정 순서로 겹쳐진다. 새 패널이 아래에서 올라오고 이전 패널은 그 아래에 남아 있어, 문서가 단순히 아래로 이동한다는 느낌보다 카드를 넘기는 느낌을 준다.
4. **번호별 스토리텔링**: FEATURE 1~7은 왼쪽의 고정된 번호와 오른쪽의 서로 다른 증거를 한 장면씩 결합한다. 스크롤 스냅·스크롤재킹이 쓰였다고 단정할 근거는 없다.
5. **스티키 내비게이션·지속 CTA**: 상단 HOME/다운로드가 여러 화면에서 계속 나타난다. 실제 CSS `position: sticky`인지 `fixed`인지는 미확인이다.
6. **지속 회전하는 번호 도형**: 둥근 파란 정사각형은 회전하고 숫자는 정방향으로 유지된다. 장식이면서 1~7 순서를 알려주는 길잡이다.
7. **오른쪽에서 날아오는 카드**: 각 증거 묶음이 투명·축소·오른쪽 이동 상태에서 보이는 위치로 전환한다. 정지한 최종 상태와 별개의 입장 효과다.
8. **시각적 비교 데모**: 효익을 설명하는 문단 대신 실제 글꼴과 수치를 직접 대조해 납득시킨다. 이 사이트의 핵심 설득 장치다.

## 제작 에이전트가 가져갈 것과 피할 것

- 가져갈 것: 제품의 가장 강한 한 문장을 큰 글자로, 고대비의 2~3개 색면, 아래에서 올라와 겹치는 패널, 고정된 순차 번호, 증거 카드의 측면 진입, 실제 동작하는 지속 CTA.
- 상황에 맞게 바꿀 것: 패널 색·모서리·비교 형식·폰트. 폰트 쇼케이스가 아닌 제품에는 실물 사진, 인터랙티브 데모 또는 측정 가능한 증거를 주인공으로 둔다.
- 피할 것: `PAPERLOGY.` 워드마크나 원본 문구·정확한 배치를 복제하는 일, 패널/번호/진입 효과를 단순 페이드 한 종류로 뭉개는 일, 모든 섹션에 무거운 스크롤 모션을 거는 일, 모바일에서 잘림을 방치하는 일.
- 원본의 Paperlogy 글꼴 자체가 필요하면 원본의 다운로드 및 라이선스 조건을 별도로 확인한다. 레퍼런스 스타일을 따른다는 이유로 폰트 파일을 무단 내장하지 않는다.

## 추천 제작 순서

콘텐츠/CTA 정의 → 레퍼런스와 대상 브랜드의 차이 정리 → 타이포 스케일·색면·그리드 설계 → 증거 섹션 제작 → 필요한 장면에만 모션 적용 → 모바일·키보드·`prefers-reduced-motion` 검수.
