# Editorial type layout

Start from the user's product claim, audience, evidence, and CTA. Choose one dominant message per visual scene. Use a small, brand-appropriate color system and a deliberate display/body type scale; the display line may crop at large viewports, but essential information must remain fully readable. Set line lengths and spacing before shrinking type.

Build rhythm through alternating open whitespace and dense color-field panels. Use split editorial grids when a claim can sit beside a real demonstration. Prefer side-by-side specimens, annotated images, or quantified comparisons over decorative cards. Reserve huge numerals and rotated badges for genuine sequence or measurable value.

Adapt the reference's visual grammar to the brand. Do not copy its exact `PAPERLOGY.` wordmark, copy, full section order, or proprietary visuals. Check font license before bundling any non-system font. Ensure the layout collapses intentionally on narrow screens rather than merely scaling down.
